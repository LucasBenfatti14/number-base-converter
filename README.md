## 🚀 Sobre o projeto

Este projeto consiste em um conversor de bases numéricas desenvolvido em Python.

O sistema permite converter números decimais inteiros e positivos para Binário, Octal e Hexadecimal através da implementação manual dos algoritmos de conversão, sem utilizar as funções nativas da linguagem (`bin()`, `oct()` e `hex()`).

O objetivo do projeto foi praticar lógica de programação, estruturas de repetição, funções, validação de dados e manipulação de listas.
